# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, criticise ideas rather than people, and keep
discussions about the work. Harassment, insults, discriminatory language, personal attacks and publishing
someone else's private information are not acceptable, in issues, pull requests, discussions or any other
project space.

## Reporting

If someone's behaviour makes you uncomfortable, report it privately to the maintainers through
[GitHub's private reporting](https://github.com/zipluciano/finnick/security/advisories/new) (choose any
title; reports about conduct are handled separately from security) or by using GitHub's
"Report content" option on the comment. Every report is reviewed and kept confidential.

Maintainers may remove comments, commits or other contributions that break this code, and may warn,
temporarily ban or permanently ban anyone who does, following the Covenant's enforcement guidelines.
